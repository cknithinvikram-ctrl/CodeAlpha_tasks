Files:
- Connecting_Rod.stl : Actual watertight 3D mesh model (millimetres)
- Connecting_Rod.scad : Editable parametric source model
- Connecting_Rod_Isometric.png : Generated isometric preview of the STL geometry

Design dimensions:

- Big-end outside diameter: 40 mm
- Big-end through-hole diameter: 20 mm
- Small-end outside diameter: 25 mm
- Small-end through-hole diameter: 12 mm
- Shank width: 15 mm
- Thickness: 10 mm
- Centre-to-centre distance: 117.5 mm

IMPORTANT:
The STL is a real 3D geometry file, but it is not a native SolidWorks feature-history file.
To create the required native SolidWorks part:
1. Open SolidWorks.
2. File > Open and select Connecting_Rod.stl.
3. In the import options, select Import as: Solid body (if offered), units: millimetres.
4. Save As > Part (*.sldprt).
5. Assign Aluminium Alloy 6061 in the Material tree if available in your SolidWorks material library.
6. Create a drawing from the part (File > Make Drawing from Part) and place Top, Front, Right and Isometric views.
7. Save the drawing as .SLDDRW and export PDF.
8. Capture screenshots from the SolidWorks viewport for evidence.

The supplied PNG is a generated preview, not a screenshot from SolidWorks.
The model geometry has been checked as watertight. Validate dimensions and fit for any real mechanical use; this is an educational CAD model, not a production-ready engine component.
